# prototype —— 早期原型，**不要用于正式数据库**

这里是本项目正式规格（三条铁律 + 附录 A/C/D）确定之前写的探索性代码。
保留它是因为里面的中英文溢价/折价正则在阶段三可能有参考价值。

## 为什么不能直接用

它违反了后来确立的多条铁律：

- **违反铁律三**：字段不带 `source_quote` / `page`，无出处。
- **未实现附录 A**：要约类型的判定只看标题关键词，不是附录 A 的判定规则。
- **未实现附录 D 的任何校验**：V3~V11 一条都没有。
  附录 D-2（折溢价方向标反）这类错误它会原样抄进结果，而且看不出来。
- **未实现附录 C**：框线摘要、三列表格、扫描件 OCR、繁简异体字，全部没处理。
- 只取"第一个看起来对的百分比"，不做多情境取最大值（附录 D-4）。

## 阶段三重写时可以捡回来的部分

`hkex_offers/extract.py` 里有一个还算有用的想法：
**比较基准要从百分比所在的那一小句里判断，不能用固定宽度的上下文窗口**。
公告常连续列好几个比较（对最后交易日、对 5 日均价、对每股净值），
窗口取宽了基准就会串味。这一点在阶段三重写时应当保留。

```bash
cd prototype && python -m pytest tests -q
```
